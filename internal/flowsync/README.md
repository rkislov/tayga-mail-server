# FlowSync

Оригинальный модуль синхронизации, разработанный Кисловым Романом Сергеевичем. Авторские права на модуль принадлежат автору; модуль распространяется отдельно под [Apache License 2.0](LICENSE), см. [NOTICE](NOTICE).

Поддерживает совместимые интерфейсы ActiveSync, EWS и Autodiscover. Исходный код не является форком Z-Push, SOGo или OpenChange.
