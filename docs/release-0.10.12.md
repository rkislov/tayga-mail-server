# Tayga Mail Server v0.10.12

- Целевой контракт Mattermost API обновлён до 12.0.0, Plugin SDK — до 0.6.1.
  Добавлены приёмочные проверки пакетов GitHub, GitLab и BigBlueButton,
  аватары ботов и дополнительные проверки изоляции доменов/тенантов.
  Хост плагинов реализует частичный API; рабочие OAuth и внешние интеграции
  требуют отдельной настройки и приёмки.
- EWS: добавлен профиль ItemAttachment<Message> для существующего события
  календаря. Поддерживаются MIME и структурированное письмо, чтение файлов
  внутри MIME, удаление с отзывом доступа и атомарная смешанная загрузка.
  В других клиентах письмо доступно как `.eml`. Вложенные события, контакты,
  задачи и произвольные расширенные свойства остаются вне профиля.
- EWS сохраняет доступ к исходному MIME и доступным метаданным архивных писем
  при повреждённой структуре MIME; ошибки чтения файлов не маскируются.
- Для ответов DAV и FlowSync явно заданы типы содержимого и защита от HTML-sniffing.
- Автоматическая приёмка зашифрованного восстановления проверяет историю чата,
  фото, сессии, очередь push и ключи Jitsi/TURN; пропавшие и обрезанные вложения
  отклоняются. Полное восстановление рабочей установки требует отдельного стенда.
- Сохранены общий чат TMS/Mattermost, групповые звонки Jitsi из канала и
  исправленный полноэкранный просмотр фото на iPhone из 0.10.11.

Перед обновлением сохраните резервную копию БД, конфигурации и файлового
хранилища. Миграция 074 добавляет тип календарного вложения в SQLite/PostgreSQL;
существующие вложения остаются обычными файлами. Thunderbird-пакет — 2.5.0.
