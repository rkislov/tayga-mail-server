# Tayga Mail 0.9.40 — защищённый вход XMPP и WebSocket

Релиз добавляет SASL2 и SCRAM, сохраняя текущие подключения по паролю, пароли устройств и политики доступа. В него также входит защищённый WebSocket для XMPP.

## Вход XMPP

- SASL2 с проверкой идентичности и выдачей новых возможностей без перезапуска XML-потока.
- SCRAM-SHA-256/PLUS на TCP, привязка к TLS exporter и сертификату, защита списка механизмов по XEP-0474.
- Постепенная подготовка существующих паролей после успешного входа через TLS. Новые пароли устройств готовы сразу; смена основного пароля атомарно обновляет верификаторы.
- LDAP продолжает проверять основной пароль в каталоге. TOTP, режим «только пароли устройств», отключение пользователя и отзыв устройства учитываются при входе. Пароли и ключи OMEMO не сбрасываются.

Подробности и ограничения перехода: [SASL2/SCRAM](xmpp-sasl2.md). Старые Argon2-хеши нельзя преобразовать без успешной проверки исходного пароля. SCRAM объявляется только для подготовленных учётных записей с `from` в stream header. Реальная приёмка нового механизма в Monal/Conversations остаётся отдельной проверкой после обновления.

## WebSocket

- Опциональный `/xmpp-websocket`, RFC 7395, только HTTPS и подпротокол `xmpp`; выключен по умолчанию.
- Same-origin для браузера, обязательный SASL независимо от cookies, ограничения кадров и числа соединений.
- Общие устройства, комнаты, OMEMO, архив MAM и восстановление Stream Management для TCP и WebSocket.
- SASL2 и SCRAM без PLUS для браузеров. Встроенный веб-чат пока использует существующий REST/SSE.

[Настройка WebSocket](xmpp-websocket.md). Автоматическое обнаружение WebSocket, Bind 2 и FAST в этот выпуск не входят.

## Подтверждённые сценарии и обновление

Пользователь подтвердил загрузку истории группы у второго участника, чтение зашифрованного сообщения и открытие групповых OMEMO-вложений в обе стороны между вебом и Monal. Эти результаты дополняют приёмку 0.9.39.

Проверки выпуска: полный Go test suite, целевые тесты с race detector, PostgreSQL/SQLite с имитацией ошибок транзакций, реальные локальные TLS-соединения и WebSocket. Тестовые сообщения рабочим пользователям не отправлялись.

Миграция 061 добавляет две таблицы SCRAM; существующие письма, календари и архивы не переписываются. Перед обновлением сохраните БД, конфигурацию и прежний бинарник. Учитывайте закрепление SCRAM клиентами при планировании отката к старым версиям. Thunderbird 2.3 не менялся. Презентация в релиз и GitHub не включается.
