# Подключение SIEM

Tayga экспортирует события входа в веб-интерфейс и почтового журнала как CEF по syslog. В **Администрирование → Сервер → Экспорт событий SIEM** задайте адрес приёмника `host:port`, протокол `udp`, `tcp` или `tls`, facility и включите экспорт. После сохранения перезапустите службу Tayga.

Пример bootstrap YAML; сохранённые настройки сервера из базы имеют приоритет:

```yaml
siem:
  enabled: true
  protocol: tls
  address: siem.example.org:6514
  facility: local0
  format: cef
  tls_skip_verify: false
```

Для TLS нужен сертификат приёмника, которому доверяет операционная система и который соответствует имени сервера. Корневой сертификат частного УЦ устанавливается в системное хранилище. Отключать проверку сертификата для рабочего подключения не следует.

На приёмнике включите совместимый syslog/CEF input. После настройки выполните обычный вход в Tayga и проверьте событие `auth:login`, время, имя пользователя и источник. Отдельно проверьте появление событий почтовой доставки. Наличие соединения само по себе не подтверждает, что SIEM разобрала событие.

Экспорт асинхронный: очередь находится в памяти, при переполнении события отбрасываются; ошибка отправки журналируется без повторной постановки. Это не гарантированная доставка и не полный аудит всех административных действий. Локальный тест проверяет получение UDP/CEF, а совместимость с выбранной SIEM проверяется на её приёмнике.

Для подключения нужны название SIEM, адрес, порт, протокол и сведения о доверенном УЦ. Секреты не следует помещать в документацию или публичные отчёты. Подключение [DLP-шлюза](mail-dlp.md) настраивается отдельно и меняет маршрут исходящей внешней почты.
