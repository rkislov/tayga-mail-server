# Tayga Mail Server 1.0.2

- Действия над письмом закреплены сверху области чтения. Содержимое письма сохраняет полную высоту; массовые действия представлены иконками с подписями для клавиатуры и подсказками.
- Компактное окно делегирования: отдельные группы прав на почту и календарь.
- Кнопки адресной книги в полях «Кому» и «Копия», выбор нескольких получателей, поиск по контактам и организационному справочнику, оформленные подсказки при вводе. Повторный выбор адреса не создаёт дубликат.
- Восстановлена вёрстка почтовых фильтров и конструктора правил. «Сохранить и включить» в редакторе записывает правило на сервер; блок правил Outlook расположен внутри содержимого настроек.
- Главный экран мониторинга показывает обработку входящей почты, CPU и оперативную память всей машины. Число сохранённых писем и техническая статистика процесса перенесены в раскрываемые подробности.
- README полностью переписан на русском и английском; описание репозитория также двуязычное.

## Показатели мониторинга

История сохраняется раз в минуту. «Принято» — успешные входящие доставки по получателям, «Отклонено» — отклонённые входящие получатели/доставки. Отдельные линии «Спам» и «Не спам» показывают результаты Rspamd: tag/quarantine/reject и pass соответственно. Эти линии пересекаются по смыслу с доставками, их нельзя складывать в общее число писем. Без включённого сканера классификации спама нет. Ошибки проверки и временные отсрочки доступны в подробной статистике.

График показывает изменение счётчиков за минуту. После перезапуска первые значения появляются со вторым наблюдением; границы перезапусков и пропуски не соединяются. История до обновления не подменяется нулями.

CPU рассчитывается по разнице суммарных счётчиков Linux `/proc/stat`; гостевое время не считается дважды, idle и iowait исключаются из загрузки. Память — `MemTotal − MemAvailable`, дополнительно показан swap. Это показатели машины, видимой процессу, а не Go heap и не лимиты контейнера. На системах без `/proc` отсутствие данных обозначается явно.

## Мобильный чат и внешние боты

- Исправлено обрезание списка чатов на телефоне; список и переписка занимают весь экран, добавлена иконка возврата, поле ввода учитывает доступную высоту экрана.
- В Mattermost добавлена вкладка «Боты»: отдельные учётные записи, токен подключения REST/WebSocket, его замена и отключение доступа. См. [инструкцию](mattermost-bots.md).
