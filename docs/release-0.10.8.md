# Tayga Mail Server 0.10.8

Исправлен формат почтовой синхронизации EWS для отображения бесед в Outlook. Расчёт ConversationId/ConversationIndex/ConversationTopic, исправление падения на часовых поясах и ускорение больших писем из 0.10.7 сохранены. Thunderbird XPI остаётся 2.4.0.

## Исправление

При SyncFolderItems с BaseShape=IdOnly сервер теперь возвращает только ItemId и явно запрошенные свойства. Раньше в этом ответе были лишние тема, даты и флаги, но не полный набор свойств беседы. Outlook получал неполную запись вместо ответа запрошенной формы. Полные свойства письма и беседы клиент получает через GetItem.

Отпечатки изменений по-прежнему вычисляются по полной внутренней записи: изменение флагов или метаданных обнаруживается даже при коротком ответе IdOnly. Старые закэшированные ответы повторных запросов приводятся к запрошенной форме. Уже соответствующие форме ответы повторяются побайтно. Календарь и контакты этот почтовый фильтр не изменяет.

## Проверки

В реальном Outlook 16.114.4 на Mac проверена новая временная папка с тремя техническими сообщениями: клиент показал «Беседа», число сообщений 3 и элементы «1 из 3», «2 из 3», «3 из 3». Проверка использовала внутреннюю доставку файлов в собственную тестовую папку без SMTP-рассылки. Обе технические папки, записи сообщений и файлы удалены после проверки.

Регрессионный тест проверяет Create/Update с IdOnly, сохранение запрошенного дополнительного свойства, распознавание изменений флага и точный повтор актуального ответа. Проверены также исправление старого сохранённого ответа, часовые пояса и свойства бесед. Пройдены полный Go-прогон, целевые race-тесты и нативный Thunderbird E2E с большим MIME, вложением и повторным открытием без новой загрузки.

Для ранее загруженных записей Outlook обновление свойств само по себе не восстановило группировку. Очистка локального кэша папки требует отдельного согласия: Outlook предупреждает о потере несинхронизированных локальных элементов. После получения согласия кэш рабочих «Входящих» обновлён: все 78 писем загружены, старые письма объединились в три беседы. Завершение синхронизации и дочерние письма раскрытой беседы проверены в клиенте.
