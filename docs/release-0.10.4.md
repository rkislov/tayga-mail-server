# Tayga Mail Server 0.10.4

Исправлен импорт копий встреч с внешним организатором через ActiveSync.
Thunderbird XPI остаётся 2.4.0.

## Исправление

Новый Calendar Add теперь может сохранить копию с внешним организатором,
в том числе из пересланного ICS, в календаре пользователя. Раньше такой Add
отклонялся как смена организатора. Новая копия использует существующий путь
личного импорта: она не рассылает приглашения/ответы, не создаёт копии
другим участникам и не бронирует ресурсы от имени внешнего организатора.

Сохраняются имя организатора и видимые статусы участников. Повторный импорт
с тем же ClientUid возвращает существующую запись. Владение календарём
проверяется внутри транзакции. Запрет изменения организатора существующего
события и состава участников полученной копии остаётся в силе; обычные
организаторские изменения по-прежнему используют штатный механизм рассылки.

## Проверки

Проверены импорт, повтор с новым ClientId, отсутствие писем и чужих копий,
отказ записи в чужой календарь, запрет переназначения организатора,
сохранение исходной записи при отказе и удаление личной копии без отмены
чужой встречи. Пройдены полный Go-прогон и целевые race-тесты.

## Клиентская диагностика

После исправления WBXML в 0.10.3 реальный iPhone в 22:26 МСК 5 ноября
подтвердил прежний ответ календаря и продвинул ключ. Старый зависший импорт
при этом сам не отправился: в журнале с 18:00 не было Calendar Add/Change
или MeetingResponse от этого устройства.

Для выбранной пользователем встречи отдельно восстановлена одна серверная
копия из исходного ICS с сохранением UID. Эта операция не выдаётся за
получение первоначального Add с телефона. При восстановлении временные
защитные триггеры запрещали создание почтовых заданий и приглашений.
В 22:37 iPhone получил восстановленную запись и отправил Change; сервер
ответил Status=1. Содержимое ICS сохранено (порядок параметров участников
нормализован), на сервере одна копия, новых записей приглашений нет.
