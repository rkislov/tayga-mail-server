# Tayga Mail Server 0.9.14

Исправлена авторизация почтовых клиентов после добавления passkey. Раньше регистрация WebAuthn-ключа включала общий запрет входа по паролю: FlowSync (ActiveSync/EWS) начинал возвращать HTTP 401. Теперь passkey защищает только вход в веб-интерфейс, а пароль продолжает работать в FlowSync, IMAP/SMTP/POP3, DAV, ManageSieve и XMPP.

- Веб-вход сохраняет проверку зарегистрированного passkey; удалять ключ и создавать учётную запись клиента заново не нужно.
- Отдельная настройка `mfa.require_token_for_mfa_users` по-прежнему требует OAuth-токен для протокольного входа при включённом TOTP. Незавершённая настройка TOTP не блокирует пароль.
- В профиле и настройках администратора уточнено, что passkey применяется к веб-интерфейсу. Обновлены инструкции по авторизации и диагностике FlowSync.
- При ошибке чтения политики TOTP сервер отклоняет авторизацию, а не пропускает проверку.

Регрессионный тест воспроизводит исходный HTTP 401 в ActiveSync и EWS и проверяет вход до/после регистрации ключа, неверный пароль, обязательный passkey для веб-входа, незавершённый и включённый TOTP, вход по токену и отключение факторов. Пройдены `go test ./...`, целевые проверки авторизации/FlowSync с `-race` и сборка фронтенда. Это серверные проверки; работу конкретного клиента Gmail/Outlook после установки нужно подтвердить на устройстве.

Выпуск также включает все изменения [0.9.13](https://github.com/rkislov/tayga-mail-server/releases/tag/v0.9.13): видимость нескольких календарей, внешние подписки iCalendar/CalDAV, инициалы вместо отсутствующего аватара, исправления XMPP и уведомлений. Ограничения этих функций перечислены в описании 0.9.13.

Перед обновлением сохраните базу, файлы, почтовые данные, конфигурацию и ключ шифрования секретов. Для применения исправления нужен новый серверный бинарный файл и перезапуск службы; изменение конфигурации и удаление passkey не требуются.

Сервер — Apache-2.0. FlowSync разработан Кисловым Романом Сергеевичем и отдельно распространяется под Apache-2.0. Веб-клиент с OMEMO — GPL-3.0-only.
