# Tayga Mail Server 0.9.21

Исправлена загрузка ключей OMEMO в Monal. Сервер теперь объявляет и обрабатывает необходимые возможности PEP/PubSub: создание узлов, публикацию с параметрами, постоянные подписки, получение и удаление элементов, удаление узлов и уведомления. Ранее Monal отключал работу с PubSub из-за неполного объявления возможностей, поэтому запросы ключей не отправлялись, а интерфейс оставался в состоянии «Загрузка ключей OMEMO».

Поддержаны параметры публикации Monal `pubsub#notify_retract` и `pubsub#notify_delete`. Уведомления отправляются как `headline` и учитывают интересы каждого подключённого устройства, явные подписки и текущие права доступа. Последние опубликованные данные доступны при обнаружении интереса или подписке; интересы устройства сохраняются при восстановлении потока. Операции изменения узлов доступны только владельцу, подписка не позволяет обойти ограничения доступа.

Добавлен корректный ответ на запрос версии сервера (XEP-0092): имя Tayga Mail, версия сборки и явные адреса отправителя и получателя. Это исправляет выявленное падение Monal при обработке прежнего ответа. Запросы к пользовательским устройствам продолжают направляться этим устройствам.

Исправлена совместимость исходящего соединения с push-шлюзом Monal, объявляющим возможность двунаправленного потока через `urn:xmpp:bidi`. Сохраняются проверка TLS-сертификата, SASL EXTERNAL, список разрешённых шлюзов и проверка адресов ответа. Для Monal шлюз `eu.prod.push.monal-im.org` нужно добавить в `xmpp.push_services`; регистрация push на рабочем сервере проверена.

Проверки: полные тесты Go; тесты XMPP и хранилища с детектором гонок; сценарии PEP, разграничения доступа, уведомлений, восстановления потока и ответов версии. На рабочем сервере проверены вход через STARTTLS на порту 5222, список контактов, запросы архива, публикация ключей Monal и чтение наборов ключей всех четырёх устройств учётной записи. Пользователь подтвердил исчезновение надписи «Загрузка ключей OMEMO».

Ограничения: обмен зашифрованными сообщениями между Monal и веб-клиентом в обе стороны и доставка уведомления до устройства через APNs ещё не подтверждены отдельной проверкой. Релиз не заявляет полную поддержку всех расширений XMPP, отображаемых в диагностике клиентов.

Добавлена миграция 045 для SQLite и PostgreSQL: параметры уведомлений PEP и постоянные подписки. Она применяется автоматически при запуске. Удаление учётных записей, сброс ключей OMEMO и состояния почтовой синхронизации для обновления не нужны. Перед установкой сохраните базу данных, конфигурацию и предыдущий бинарный файл.

Подробности: [XMPP push и совместимость Monal](https://github.com/rkislov/tayga-mail-server/blob/v0.9.21/docs/xmpp-push.md).
