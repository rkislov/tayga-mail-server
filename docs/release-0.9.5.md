# Tayga Mail Server 0.9.5

Обновление интерфейса и календарей:

- Компактные формы письма, события и контакта, единые иконки действий и новый favicon.
- Выбор писем и массовые действия, обновлённая панель страниц, подсказки контактов и упоминания через @ с добавлением в копию.
- Предпросмотр изображений и PDF внутри интерфейса; PDF отображается через локальный PDF.js без выполнения сценариев документа.
- Три последних задания миграции на странице и навигация по истории.
- Исправлен импорт CalDAV из прямой ссылки на коллекцию SOGo: отдельные запросы VEVENT и VTODO.
- Основной, персональный и рабочий календарь для каждого пользователя. При предоставлении доступа к персональному календарю другим пользователям показывается занятость без деталей.
- Ссылки CalDAV, ICS и WebDAV XML в свойствах календаря. XML содержит DAV multistatus с calendar-data.
- Поиск места события через Photon по явному запросу пользователя, сохранение геоточки и подбор свободного времени участников.
- Включаемый в настройках домена адресный справочник GAL для веб-интерфейса и подсказок адресатов.
- Генератор DKIM RSA-2048: скачивание закрытого ключа, готовая TXT-запись и подсказки по DNS и включению подписи.
- Настройки DNSBL в разделе «Антиспам → Rspamd / DNSBL»: отключены по умолчанию, результат добавляет баллы к общей оценке, авторизованная отправка исключена.

Архивы содержат сервер, пример конфигурации, systemd unit и инструкции. Доступны Linux, macOS, Windows (amd64/arm64) и FreeBSD amd64. Контрольные суммы — checksums.txt.
