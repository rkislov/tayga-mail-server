# Tayga Mail 0.9.37 — вложения OMEMO и управление устройствами

Релиз объединяет исправления истории XMPP, зашифрованных вложений и управления устройствами, ранее установленные на рабочем сервере в сборках `0.9.36+xmpp.1–4`. Пользователь подтвердил открытие файлов в обе стороны между веб-клиентом и Monal.

## OMEMO в веб-чате

- В настройках шифрования появилась кнопка **Не отправлять на устройство**. Исключённое устройство больше не получает ключ новых сообщений из этого браузера; остальные проверенные устройства продолжают получать сообщения. Настройка доступна для устройств собеседника и других собственных устройств.
- Исключение сохраняется после перезагрузки страницы, исчезновения устройства из списка и его повторного появления, в том числе с изменённым ключом. Возвращение требует сверки текущего отпечатка и явного подтверждения. Устаревшее окно проверки в другой вкладке не может отменить исключение.
- Если исключены все устройства получателя, отправка блокируется. Неизвестные и изменившиеся активные ключи по-прежнему требуют проверки; автоматического перехода на открытый текст нет. Отзыв доверия остаётся отдельным действием.
- Уже прочитанная история остаётся доступной. Новые сообщения от исключённого устройства требуют его повторного подтверждения.
- Ожидающие операции шифрования, публикации ключей, расшифровки и открытия файлов привязаны к исходному входу. Выход, смена аккаунта или повторный вход отменяют их продолжение. Запоздалое обновление токена не заменяет данные нового входа; локальные ключи сохраняются при обычном выходе.

Исключение устройства действует **только в текущем браузере для текущей учётной записи**. Оно не удаляет устройство из серверного списка, не отключает вход на нём и не меняет доверие в других клиентах.

## Зашифрованные файлы

- Новые вложения используют AES-256-GCM с 12-байтовым IV. Получение также поддерживает исторический формат Conversations с 16-байтовым IV.
- Исправлены CORS и предварительные запросы файлового сервиса: веб-клиент может загружать и скачивать шифротекст с другого origin без передачи учётных данных. Ключ из ссылки не отправляется файловому серверу.
- HEAD возвращает метаданные без тела и без увеличения счётчика скачиваний. GET и Range сохраняют исходные байты шифротекста. Обычные публичные ссылки на файлы и папки также поддерживают HEAD.
- Ссылки с некорректным ключевым материалом, встроенными логином/паролем, управляющими символами или обратной косой чертой отклоняются до скачивания.

Приёмка открытия файлов веб ↔ Monal подтверждена пользователем 29 октября 2026 года; версия Monal не записана. Совместимость формата Conversations проверена независимыми тестами, приёмка в самом приложении остаётся отдельной задачей. Используется legacy OMEMO; OMEMO 2 и шифрование веб-групп в этот релиз не входят.

## История XMPP

- Исправлено продолжение постраничного чтения MAM при смене фильтров по собеседнику или времени: положение курсора определяется в архиве владельца до применения новых фильтров.
- Неподдерживаемые, повторные и некорректные условия запроса возвращают ошибку до выдачи истории вместо молчаливого игнорирования.
- Проверен сценарий с 257 сообщениями и двумя устройствами: страницы вперёд и назад, новое сообщение между запросами, продолжение после восстановления соединения, стабильные ID и отсутствие лишних копий истории через Message Carbons.

## Проверки и обновление

Пройдены полный набор `go test ./...`, браузерные проверки доверия, четырёх устройств, изоляции аккаунтов и восстановления после повторного входа. Реальный HTTP API проверен на отдельном локальном сервере; HTTPS-сценарий проверяет загрузку через форму, PNG/PDF, скачивание точных байтов и CORS между разными origin. Формат файлов проверен независимыми реализациями Node.js crypto и Apple CryptoKit. Для изменений архива также пройдены `go test -race ./internal/xmpp` и `go vet ./internal/xmpp`.

Новых миграций БД относительно 0.9.36 нет. Существующие учётные записи и ключи сохраняются. Перед обновлением сохраните резервную копию конфигурации, БД и файлового хранилища, проверьте архив по `checksums.txt`, замените бинарник и перезапустите службу. После установки обновите веб-страницу, не очищая данные браузера с ключами OMEMO.

В релиз включены архивы для Linux, macOS и Windows (amd64/arm64), FreeBSD (amd64), контрольные суммы, документация и исходники веб-клиента с лицензией GPL-3.0. Сервер и FlowSync сохраняют Apache-2.0.
