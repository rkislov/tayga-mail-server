# Tayga Mail Server 1.0.3

Выпуск включает все изменения [1.0.2](release-1.0.2.md): мобильный чат на всю рабочую область, внешние боты Mattermost, закреплённые сверху действия над письмом, адресная книга и автодополнение, обновлённые фильтры, делегирование и показатели мониторинга.

Дополнительно: при завершении сеанса окно токена бота закрывается, секрет сразу удаляется из поля, ожидающие административные запросы теряют актуальность. Это применяется и при автоматическом выходе после истечения авторизации.

1.0.2 отмечает промежуточное состояние исходников; установочные архивы публикуются для 1.0.3. Обновлённые снимки интерфейса находятся в [галерее](screenshots/README.md), подключение ботов описано в [инструкции](mattermost-bots.md).
