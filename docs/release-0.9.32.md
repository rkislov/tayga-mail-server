# Tayga Mail 0.9.32 — ONLYOFFICE / Р7 и Thunderbird EWS 2.0

Общий релиз сервера с офисной интеграцией ONLYOFFICE / Р7 и актуальной поддержкой Thunderbird-плагина Tayga Mail 2.0.0.

- Добавлена проверка `TaygaSyncVersion=1` через GetFolder: плагин проверяет поддержку полного обмена до передачи локальных правок.
- Полный обмен iCalendar/vCard сохраняет повторения, исключения и дополнительные поля; запись проверяет текущую версию объекта.
- Повтор создания после потери ответа использует прежний идентификатор, без дублирования объекта.
- Исправлен ответ CreateItem при отправке почты: успешный ответ содержит контейнер Items, который ожидает Thunderbird.
- SaveOnly учитывает выбранную папку пользователя: Thunderbird может сохранить отправленную копию в Sent без ошибочного флага Draft.

Плагин 2.0.0 переустанавливать не требуется. После обновления серверного бинарника и перезапуска службы нажмите «Синхронизировать сейчас» в настройках плагина. Конфигурация и каталог данных сохраняются.

## ONLYOFFICE / Р7

- Открытие документов из «Файлов» через Document Server API, совместное редактирование и просмотр по правам Tayga.
- JWT-подписи, проверка callback, промежуточное и итоговое сохранение с версиями, квотами и блокировками WebDAV.
- Подключение в веб-админке: «Настройки сервера → Хранение и доступность → Файлы и офис · ONLYOFFICE / Р7»; в консоли: «Настройки сервера → Файлы и офис».
- Collabora Online остаётся провайдером по умолчанию. [Настройка и ограничения](files-and-office.md).

## Состав и обновление

В релиз включён XPI `tayga-thunderbird-v2.0.0.xpi`. Он требует Thunderbird 145+; сервер и плагин должны обновляться согласованно. Проверка совместимости использует `TaygaSyncVersion=1`.

Сборка включает накопленные изменения календарей и вложений, алиасы отправителей, версии и синхронизацию заметок, оформление входа и документацию HA. В исходниках есть миграции 054 (алиасы) и 055 (версии заметок). Перед обновлением сохраните резервную копию БД и файлового хранилища.

Проверка офисной интеграции выполнена на локальном HTTPS-стенде; ручная проверка с действующим ONLYOFFICE / Р7 пока не выполнена. Проверка Thunderbird использует временные профиль, БД и Maildir без рабочих аккаунтов.
