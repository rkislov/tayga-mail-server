# Tayga Mail Server 0.10.0

Большой выпуск календаря, совместной работы с файлами и Thunderbird. Основа — опубликованная 0.9.44: сохраняются исправления IMAP и мобильных фотографий, задачи Thunderbird, XMPP/OMEMO, SASL2 и полные зашифрованные резервные копии.

## Календарь

- Ответ участника на отдельное повторение: принять, отклонить или предварительно принять одну дату без изменения всей серии.
- Предложение другого времени одной даты с отдельной ревизией и транзакционным решением организатора; защита от устаревшей версии и конкурентных изменений.
- Двусторонний EWS/ActiveSync для поддерживаемых правил повторений, перенесённых и отменённых исключений. Идентификатор исходной даты сохраняется при переносе; неподдерживаемое правило отклоняется без потери серии.
- EWS: изменение участников, файловых вложений и встречи через общую транзакцию; режимы рассылки всем либо изменённым участникам, постоянная очередь копий в Sent.
- Локальный CalDAV scheduling: discovery, постоянный inbox, outbox VFREEBUSY, ответ участника через PARTSTAT, Schedule-Tag и проверка конкурентной записи.

## Файлы и офис

- Общие папки WebDAV, WOPI Save As/PutRelativeFile и шаблоны документов с проверкой прав.
- Расширены сравнение версий документов, таблиц и презентаций, статичный просмотр страниц/слайдов и ограниченное воспроизведение анимаций.
- Поддерживаемый профиль анимаций включает согласованные изменения нескольких свойств, последовательные стадии и конечные повторения; неподдерживаемые эффекты показываются статично с предупреждением.

## Thunderbird 2.4.0

- Объединены задачи и полные серии VTODO из выпущенной 2.3.0 с новыми ответами на приглашения, диагностикой без секретов и восстановлением Filelink-загрузок.
- Общая сессия EWS, обновление авторизации нативных запросов после сна и восстановление при возвращении сети.
- Светлая тема Tayga. Плагин поставляется отдельным XPI в этом релизе; установка в рабочий профиль выполняется отдельно.

## Обновление

Новые миграции **062–064**: предложения времени отдельных повторений, назначения почтовых копий календаря и CalDAV scheduling. Номера 056–061 сохраняют опубликованную схему 0.9.44. Миграции применяются при запуске; действующий YAML заменять не требуется.

Перед обновлением остановить Tayga и сохранить согласованный снимок БД, Maildir, файлов, настроек, серверных ключей и текущего бинарника. Для поддерживаемой установки SQLite см. [полное резервное копирование](backup-full.md). Откат бинарника не отменяет миграции; восстановление данных выполняется из проверенной копии при остановленной службе.

## Проверки и границы

Пройдены общий `go test ./...`, сборка веб-интерфейса, 61 Node-проверка плагина и нативный цикл Thunderbird в отдельном временном профиле, включая задачи, повторения и очередь после перезапуска. Race-проверки календаря, DAV, FlowSync, хранилища и HTTP пройдены; GitHub CI, Release workflow и повторный CodeQL успешны.

Не объявляется полная поддержка RFC 6638 или всех правил Exchange. Внешний iTIP, вложенный EWS ItemAttachment, расширенная матрица Outlook/iPhone/DAV, PostgreSQL и рабочие офисные серверы требуют отдельных проверок. Физическая HA-приёмка и восстановление рабочего сервера на чистом узле остаются в [дорожной карте](roadmap.md).
