# Tayga Mail Server 0.10.6

Ускорена фоновая синхронизация почты Thunderbird/EWS, особенно во время повторной загрузки заголовков после восстановления папки. Объединение ответов в цепочки из 0.10.5 сохранено. Thunderbird XPI остаётся 2.4.0.

## Исправления

При проверке папки EWS загружает пользовательские метаданные одним SQL-запросом вместо отдельного запроса для каждого письма. Для стандартных писем без дополнительных свойств сохранены прежние значения по умолчанию, ChangeKey и отпечатки синхронизации; посторонние папки не попадают в выборку. Это уменьшает конкуренцию за базу между фоновыми проверками и открытием писем.

Чтение метаданных MIME прекращается сразу после обнаружения первого вложения. Для простого письма проверяются заголовки единственной части. Не требуется дочитывать весь большой файл, если клиенту нужен только HasAttachments. Полная загрузка MIME и получение вложений используют прежний путь и сохраняют содержимое.

## Проверки

В локальном benchmark на 1000 индексированных писем список обрабатывался примерно за 4,4 мс вместо 22,1 мс (Apple M4, пять итераций; это измерение серверной операции, а не обещание времени открытия любого письма). Тесты чтения метаданных 8-МБ сообщений потребовали 49 байт для простого письма и 170 байт для письма с первым вложением. Проверены изоляция папок, пользовательские категории, флаги и отсутствие SQL-запросов по одному на письмо. Выполнены полный Go-прогон, целевые race-тесты и нативный Thunderbird E2E с цепочками и вложениями.
