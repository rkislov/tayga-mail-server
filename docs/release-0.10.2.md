# Tayga Mail Server 0.10.2

Дополнительное исправление ActiveSync после 0.10.1. Thunderbird XPI остаётся 2.4.0.

## Исправление

В старых импортированных сериях встречается RRULE с UNTIL раньше DTSTART.
Сервер больше не передаёт перевёрнутый диапазон повторений: нижняя граница
Calendar:Until — начало первого экземпляра. DTSTART остаётся первым экземпляром
по RFC 5545; исходный ICS и исключения не переписываются. Корректные диапазоны
сохраняются. Это дополнение к исправлению Compact DateTime в 0.10.1.

Исправляется также ранее сохранённый ответ синхронизации. SyncKey, ServerId,
результаты операций и исключения сохраняются; принятые клиентские Add повторно
не выполняются. Даты других пространств имён не меняются.

## Проверки и приёмка

Общий `go test ./...` и целевой прогон с `-race` прошли.

Добавлены регрессии для диапазонов до/на/после первого события, старого RFC3339
и компактного представления, повторного ответа с клиентским Add, сохранения
отменённого экземпляра, WBXML и идемпотентности ремонта. Ручная приёмка импорта
встречи с iPhone фиксируется отдельно: устранение некорректного ответа само по
себе ещё не подтверждает передачу конкретной встречи с устройства.

Источники: [RFC 5545, recurrence set](https://www.rfc-editor.org/rfc/rfc5545.html#section-3.8.5.3),
[MS-ASCAL, Until](https://learn.microsoft.com/en-us/openspecs/exchange_server_protocols/ms-ascal/6c21532b-f302-4f98-9eaf-05e1ff723f4a).
