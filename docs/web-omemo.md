# OMEMO в веб-чате

В личном чате откройте кнопку **Шифрование: вкл./выкл.** возле имени собеседника. Браузер создаст собственное устройство и опубликует публичные ключи. В окне отдельно показаны **Устройства собеседника** и **Мои устройства**, а также состояние шифрования. Для непроверенного устройства раскройте **Проверить устройство**, сравните отпечаток с самим устройством или через другой доверенный канал и нажмите **Отпечатки совпадают — доверять**. Затем включите шифрование чата. В подробностях можно скопировать отпечаток, отозвать доверие или задать удобное название, например «iPhone»; название сохраняется только в этом браузере для текущей учётной записи. В Conversations также подтвердите новое веб-устройство. После этого отправьте новое сообщение в обе стороны.

Реализован legacy OMEMO (`eu.siacs.conversations.axolotl`, XEP-0384 0.3), используемый Conversations. Криптографические сессии выполняет libomemo.js 3.0.0. Недоступный ключ отмечается в карточке и не мешает просмотреть остальные устройства. Кнопка **Обновить устройства** повторно получает ключи. Изменившийся ключ требует новой проверки; прямо перед подтверждением браузер ещё раз сверяет его с сервером. Неизвестный или изменившийся ключ блокирует отправку; автоматического перехода на открытый текст нет. Поддерживаются несколько устройств, сообщения вне очереди и восстановление сессии после перезагрузки страницы.

Приватные ключи и локальная расшифрованная история находятся в IndexedDB браузера, раздельно для учётных записей. Сервер хранит публичные ключи и зашифрованные сообщения. Очистка данных браузера уничтожает приватные ключи; старые сообщения, не зашифрованные для этого устройства, восстановить нельзя. Используйте доверенный браузер и HTTPS. Выход из аккаунта не удаляет локальное хранилище ключей.

Вложения шифруются AES-256-GCM по XEP-0454 до загрузки. В папке `chat` сервер хранит зашифрованный файл; ключ передаётся внутри OMEMO-сообщения. Фото и PDF можно открыть в браузере после расшифровки. Лимит шифрованного файла в веб-клиенте — 64 МиБ (Web Crypto обрабатывает его в памяти). Срок ссылки — 7 дней. Обычная загрузка в файловое хранилище сохраняет отдельный лимит 10 ГиБ. Чужой файловый сервер должен разрешать CORS; ключ никогда не передаётся ему в запросе.

Пока не поддерживаются OMEMO 2, шифрование веб-групп и федерация S2S. Проверки выполняются между независимыми браузерными устройствами; сквозная проверка с реальным приложением Conversations должна быть выполнена после настройки доверия. Независимый аудит криптографической интеграции не проводился.

Проверки: `node scripts/check-omemo.mjs`, `node scripts/check-omemo-settings.mjs`, `go test ./internal/xmpp ./internal/httpapi ./internal/flowsync ./internal/storage`.

## Лицензии и исходный код

Веб-клиент с OMEMO распространяется под GPL-3.0; текст — `frontend/LICENSE`. Серверный Go-код и отдельный модуль FlowSync остаются под Apache-2.0. Исходники веб-клиента находятся в `frontend/src`, сборка — `npm ci --prefix frontend && npm run build --prefix frontend`. Исходники libomemo.js 3.0.0: https://github.com/conversejs/libomemo.js (пакет и точные версии закреплены в `frontend/package-lock.json`). Лицензия библиотеки поставляется в `/assets/libomemo-LICENSE.txt`.

Спецификации: https://xmpp.org/extensions/attic/xep-0384-0.3.0.html и https://xmpp.org/extensions/xep-0454.html.
