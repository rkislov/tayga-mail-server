# Tayga Mail 0.9.33 — вложенные папки Thunderbird

Исправлена остановка нативной синхронизации EWS с `NS_MSG_ERROR_FOLDER_MISSING`: дочерняя папка могла передаваться раньше родительской из-за сортировки по UUID. Изменения иерархии теперь сортируются с учётом родителей до разбиения на страницы.

Вложенные папки получают собственное имя в DisplayName и отдельный ParentFolderId. Стандартная папка Inbox определяется по принадлежащему пользователю ID; одноимённая вложенная папка не может подменить её.

Серверное исправление совместимо с плагином 2.0.1. После обновления выполните синхронизацию. Удалять почтовый аккаунт не требуется.

Проверки: пакет flowsync, порядок папок при постраничной выдаче, стандартные папки с совпадающими вложенными именами, реальный Thunderbird с трёхуровневой вложенностью и полным EWS-обменом.
