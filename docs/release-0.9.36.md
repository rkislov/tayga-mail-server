# Tayga Mail 0.9.36 — быстрое открытие писем в Thunderbird

Релиз устраняет задержки открытия писем в Thunderbird при фоновой синхронизации больших папок через EWS. Исправления проверены в Thunderbird и на рабочем сервере: пользователь подтвердил быстрое открытие ранее зависавших писем.

## Thunderbird / EWS

- Синхронизация использует сохранённые заголовки писем вместо повторного чтения их содержимого и вложений. Для старых записей без заголовков читается только начало файла; поддерживаются сжатые архивные письма и файловый кэш объектного хранилища.
- Синхронизация разных папок, клиентов и пользователей больше не ждёт общей блокировки. Повторные запросы одного курсора остаются последовательными и возвращают прежний результат, если клиент повторяет уже обработанный запрос.
- GetItem учитывает запрошенные свойства ItemShape. Загрузка списка писем больше не передаёт ненужный HTML и содержимое вложений. В проверенном сценарии ответы со свойствами писем сократились с сотен килобайт примерно до 23 КБ.
- При открытии письма через IdOnly + IncludeMimeContent сервер передаёт исходный MIME без преобразования. Ограничения предпросмотра отдельных MIME-частей больше не препятствуют загрузке оригинала письма, в том числе с большим вложением.

## Обновление

Релиз совместим с существующей конфигурацией и не добавляет миграций БД относительно 0.9.35. Пересоздавать учётную запись, очищать почтовый кэш или переустанавливать расширение Thunderbird не требуется.

Перед заменой бинарника сохраните резервную копию конфигурации, БД и файлового хранилища. Выберите архив для своей ОС и архитектуры, проверьте его по `checksums.txt`, замените бинарник и перезапустите службу. В этой версии сохранены исправления XMPP из [0.9.35](https://github.com/rkislov/tayga-mail-server/releases/tag/v0.9.35).

## Проверки

- Полный набор `go test ./...` и `go vet ./internal/flowsync ./internal/mailstore`.
- Проверка гонок `go test -race ./internal/flowsync ./internal/mailstore`.
- Проверки параллельной синхронизации папок, повторов запросов и отмены ожидания.
- Загрузка исходного MIME с вложением больше 32 МиБ, компактный ответ со свойствами, проверка прав доступа и чтение сжатых писем.
- Настоящий Thunderbird с отдельным тестовым профилем: получение списка и оригинала письма, изменение признака прочтения, отправка с вложением в локальный тестовый обработчик, синхронизация календарей и контактов, восстановление очереди после перезапуска.
