# Tayga Mail 0.9.31

Добавлена интеграция с отдельно установленными ONLYOFFICE Document Server и Р7 — Сервером документов через Document Server API.

- Открытие документов из раздела «Файлы», совместное редактирование и режим просмотра согласно правам Tayga.
- Подписанная JWT-конфигурация редактора и проверка callback-запросов. Права и состояние учётной записи повторно проверяются при обращениях к файлу.
- Промежуточное и итоговое сохранение создают версии и учитывают квоту владельца. Блокировки защищают от конкурирующей записи из веба и WebDAV.
- Подключение настраивается в веб-админке: «Настройки сервера → Хранение и доступность → Файлы и офис · ONLYOFFICE / Р7». В консоли `tayga menu` добавлен пункт «Настройки сервера → Файлы и офис» с выбором редактора, HTTPS-адресом, JWT-секретом и отключением интеграции.
- Подключение Collabora Online через WOPI сохраняется; это провайдер по умолчанию.

Нужны `files.office_provider` (`onlyoffice` или `r7`), `files.office_url` и общий `files.office_jwt_secret` длиной от 32 байт. Порядок настройки, ограничения форматов и сценарий приёмки описаны в [Файлы и офис](files-and-office.md).

Протокольные проверки используют локальный HTTPS-стенд. Ручная проверка с действующим ONLYOFFICE / Р7 пока не выполнена; для первой проверки используйте искусственные DOCX/XLSX/PPTX. Новых миграций БД для офисной интеграции нет.
