## Резервная копия и откат

До замены бинарника создан зашифрованный age-снимок остановленной установки
на компьютере администратора, вне репозитория. Архив — 2 567 557 494 байта;
расшифровка, полное чтение tar и SHA-256 для 59 500 файлов выполнены.
Хеш прежнего бинарника и счётчики извлечённой БД совпали с исходным снимком;
SQLite `integrity_check` — `ok`.

Это согласованный tar+age-снимок Tayga, а не формат `backup-full` с его
логической проверкой всех ссылок. В копию входят БД, Maildir, файлы, конфигурация,
ключи и бинарник. Исключены предыдущие бэкапы, журналы и отдельная установка,
исходники и сборка Rspamd. Внешние сервисы требуют собственной копии.

До обновления обнаружены 169 нарушений внешних ключей: 168 строк
`travel_jobs → messages` и одна `ews_mail_metadata → messages`. После обновления
числа и типы нарушений совпали; данные сохранены. Ранее зафиксированная
отсутствующая исходная почта также остаётся отдельной задачей. Полное
восстановление рабочего сервера на чистом узле этим обновлением не подтверждается.

Прежний бинарник и конфигурация дополнительно сохранены на сервере в
`/var/lib/tayga/backups/pre-0.10.0-20261105-200544/`. Для отката остановить
службу; возврат бинарника не отменяет миграции. Данные восстанавливать из
согласованного снимка только при остановленной службе с учётом новой почты,
поступившей после снимка.

## Проверки выпуска

Успешны общий Go-прогон, отдельный `CGO_ENABLED=0 go test ./...`, race-проверки
calutil/DAV/FlowSync/storage/HTTP, сборка фронтенда, 61 Node-тест и нативный
Thunderbird с временным профилем и перезапуском. GitHub CI и Release workflow
завершены успешно; опубликованы семь серверных архивов, XPI 2.4.0 и checksums.

CodeQL первоначально пытался автоматически собрать одиночный Swift-скрипт
проверки криптографии без Swift-проекта. Конфигурация уточнена для Actions, Go,
JavaScript/TypeScript и Python; повторный анализ и загрузка результатов успешны.
Установка XPI 2.4.0 в рабочий профиль Thunderbird остаётся отдельным действием.
