# Tayga Mail Server 0.10.5

Исправлено объединение ответных писем в цепочки в Thunderbird с учётной записью Tayga EWS. Выпуск основан на 0.10.4 и сохраняет её исправления. Плагин Thunderbird остаётся версии 2.4.0: исправление находится на сервере.

## Изменения

EWS передаёт исходные RFC Message-ID, References и In-Reply-To. Список FindItem/SyncFolderItems включает Message-ID, а GetItem возвращает полные связи ответов. Идентификаторы хранилища не подменяют Message-ID. Поддерживаются цепочки с переносами строк в References и ответы только с In-Reply-To. Сохраняется выбор полей ItemShape, включая получение метаданных без декодирования больших вложений.

Для уже синхронизированных писем сервер выдаёт обновление метаданных. Thunderbird при этом сохраняет прежний индекс цепочек: после установки сервера откройте свойства нужной почтовой папки и один раз нажмите «Восстановить папку» (Repair Folder). Для новых писем восстановление не требуется. В списке писем должен быть включён режим цепочек.

## Проверки

Регрессионные тесты EWS проверяют идентификаторы, XML-экранирование, References с переносами строк, ответы без References и однократное обновление старых метаданных без создания дубликатов. Нативный тест Thunderbird проверяет обновление старых заголовков и восстановление папки: четыре связанных письма объединяются, постороннее остаётся отдельно. Также выполняются полный Go-прогон и целевые race-тесты.
