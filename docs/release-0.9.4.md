# Tayga Mail Server 0.9.4

Подготовка следующего релиза после 0.9.2. Поддерживаемые сборки: Linux и macOS amd64/arm64, Windows amd64/arm64, FreeBSD amd64.

## Исправления

- Перенесённые письма: разбор вложенных MIME, Base64, quoted-printable, UTF-8 и Windows-1251, декодирование заголовков и имён вложений, скачивание вложений с проверкой владельца.
- HTML-письма отображаются в изолированном iframe с CSP и sandbox. Разметка ограничена шириной читателя. Активное содержимое удаляется; внешние изображения заблокированы до разрешения пользователя. Разрешения на загрузку изображений хранятся в учётной записи.
- Постраничная навигация, сортировка всей папки и результатов поиска, быстрые фильтры непрочитанных/отмеченных писем, значок вложения рядом с датой.
- Двойной клик открывает письмо, событие календаря или контакт в отдельном окне. Письма: ответ, ответ всем, спам, архив, удаление. Контакты: редактирование и письмо. События: создание похожего события и удаление.
- Форма календаря адаптируется к экрану; повтор загрузки вложения после ошибки не создаёт ещё одно событие.
- Отдельная вкладка «Антиспам»: ограниченная по ширине таблица, поиск по папке/типу/тексту, подробный отчёт в модальном окне, восстановление во входящие и удаление. Декодированы заголовки карантина.
- Настройки Rspamd, ClamAV, SPF, DKIM, DMARC и серого списка доступны из вкладки антиспама.
- Мониторинг показывает решения антиспама и количество проверенных рассылок с List-Unsubscribe. Счётчики считаются по получателям с запуска процесса; после перезапуска обнуляются. Это не историческая статистика Rspamd и не оценка рекламного содержания.
- В формах переноса IMAP/CalDAV/CardDAV есть отключённая по умолчанию опция проверки сертификата старого сервера. Исключение действует только в конкретной задаче. DAV не передаёт реквизиты по редиректу на другой origin.
- Профиль: имя, подпись новых писем/ответов, параметры безопасности; выбор языка в верхней панели. Упорядочены таблицы пользователей и диалоги сертификатов.
- Исправлено чтение старых SQLite дат и завершение IMAP соединений.

## Билеты и календарь

В действиях письма доступна кнопка «Поездка в календарь». Из текста и PDF с текстовым слоем извлекаются явно обозначенные рейс/поезд, дата и время отправления/прибытия, маршрут, место, вагон, бронь и пассажир. Перед сохранением пользователь проверяет данные и выбирает UTC-смещения отправления и прибытия.

Ограничения первой версии: распознаются подписи полей на русском/английском, даты `ДД.ММ.ГГГГ`, `ДД/ММ/ГГГГ`, `ГГГГ-ММ-ДД` и время `ЧЧ:ММ`. Таблицы авиакомпаний с другим расположением полей, несколько сегментов в одном документе, OCR сканов и автоматическое определение часового пояса пока не поддерживаются. Отсутствующее время прибытия нужно указать вручную. События не создаются автоматически при получении письма.

Для PDF установите Poppler (`pdftotext`) и обеспечьте доступ через PATH службы Tayga. На Ubuntu:

```bash
sudo apt-get install poppler-utils
sudo -u tayga pdftotext -v
```

PDF обрабатываются локально без отправки в сторонние сервисы. На документ: до 8 МиБ, первые 10 страниц, 10 секунд, до 512 КиБ извлечённого текста; не более четырёх PDF одного письма и двух процессов одновременно. Windows/macOS требуют установленного Poppler; базовый сервер работает без него.

## Обновление

Используйте [инструкцию установки](setup.md) и [ClamAV/Rspamd](setup-filters.md). Остановите Tayga и сохраните базу через SQLite backup API, конфиг/секрет и maildir. Замените бинарник, не очищая данные. Дождитесь штатной остановки миграций; прерванные задачи должны быть возвращены в pending с сохранением cursor. После запуска проверьте службу, API, IMAP и активные задачи импорта. Обновите страницу браузера с очисткой кэша.
