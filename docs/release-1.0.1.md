# Tayga Mail 1.0.1

Исправления рабочего пространства по отзывам пользователей.

- **Чаты:** аватары или инициалы в списке диалогов, у собственного профиля и рядом с сообщениями. Меню статуса сохраняет «В сети», «Отошёл», «Не беспокоить» и «Не в сети». Создание диалога/канала, каталог каналов, участники, звонок и ответ представлены иконками с доступными подписями и подсказками.
- **Вложения Mattermost:** прикрепление до пяти файлов общим размером до 1 ГиБ, перетаскивание и вставка изображений. Можно отправить файлы без текста. Документы показываются с обозначением формата, именем, размером и скачиванием; поддерживаемые изображения — с превью. Загрузка выполняется с авторизацией текущего пользователя. Автоматическое превью ограничено 12 МиБ на изображение и 32 МиБ на открытую историю; остальные файлы доступны для скачивания.
- **Почта:** высота HTML-письма определяется содержимым. Действия находятся после письма. При сворачивании навигации увеличивается область чтения, ширина списка остаётся стабильной. Скрипты в письмах по-прежнему запрещены.
- **Календарь:** единая сетка для недели и дня, компактная карточка события, аккуратный мини-календарь. Двойной щелчок по времени создаёт событие на выбранный час; Enter на колонке дня открывает создание события.
- **Файлы:** компактная карточка документа, выровненные сведения и меню дополнительных действий; оформлены блоки управления доступом и журналом.
- **Антиспам:** отдельные вкладки обзора, карантина и настроек; показатели обучения и антивируса собраны в карточки.
- **Журнал доставки:** выбор записи сразу открывает подробный статус, историю, причину ошибки и SMTP-диагностику. Связанные записи ограничены идентификатором, отправителем, получателем, направлением и областью прав администратора. Подтверждение приёма внешним сервером не обозначается как подтверждение прочтения.
- **Полные резервные копии:** восстановление на Unix принимает стандартные имена Maildir с суффиксом `:2,S`; проверки выхода за каталог сохранены. Для проверки/восстановления таких архивов используйте 1.0.1 или новее.

Схема базы данных относительно 1.0.0 не изменена. Перед обновлением сохраняйте проверенную резервную копию. Скрипт `deploy/systemd/update-binary.sh` проверяет версию и SHA-256, сохраняет предыдущий исполняемый файл и проверяет готовность сервера с доверенным TLS. `TAYGA_READY_RESOLVE` позволяет закрепить адрес проверки без отключения проверки сертификата.

Скриншоты в [руководстве пользователя](user-guide.md) и [руководстве администратора](admin-guide.md) сняты на отдельном стенде с демонстрационными данными.
