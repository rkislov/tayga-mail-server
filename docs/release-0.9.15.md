# Tayga Mail Server 0.9.15

Выпуск объединяет исправления синхронизации Apple Mail, стабильные идентификаторы XMPP и обновления интерфейса, ранее доступные в дополнительных сборках 0.9.14.

## XMPP и OMEMO

- Реализован XEP-0359: сервер назначает сообщениям UUID под bare JID локальных участников. Идентификатор совпадает в живой доставке, архиве MAM, offline-очереди, Carbons и веб-истории, включая зашифрованные сообщения OMEMO.
- Одинаковые или отсутствующие клиентские ID больше не приводят к конфликтам записей в архиве. Клиентские `id` и `origin-id` сохраняются; подставленные `stanza-id` от имени локальных участников заменяются сервером.
- Обе локальные архивные копии сохраняются одной транзакцией до доставки. Старые курсоры MAM остаются действительными; сброс истории не требуется.
- Discovery сообщает о XEP-0359 и сохраняет PEP-функции, необходимые для получения публичных ключей OMEMO.
- Устранено повторное веб-событие при отправке сообщения самому себе.

## Синхронизация почты

- Поддержана догрузка содержимого через ActiveSync `Sync/Fetch`, исправлены пустые ответы `Ping` и кодирование пустых WBXML-элементов.
- Догрузка HTML/MIME сохраняет ключ и прогресс синхронизации папки. Переключение между предпросмотром и полным письмом не вызывает повторную выдачу всей папки.
- Сохранены HTML-разметка, MIME и встроенные изображения. MIME в `AirSyncBase:Body/Data` передаётся строкой WBXML `STR_I`; бинарные вложения `ItemOperations` сохраняют `OPAQUE`.
- Исправлено зависание Apple Mail на «Загрузка» при открытии письма. Открытие ранее зависшего письма подтверждено на iPhone; это не означает проверку всех вариантов писем и клиентов.

## Интерфейс

- Расширена левая колонка календаря, исправлено расположение кнопки дополнительных действий на узком экране.
- В чате вместо отдельного большого списка статусов отображается учётная запись с цветным индикатором. Нажатие на индикатор открывает меню состояний с пояснениями.

## Проверка и обновление

Проверки покрывают все пять путей отправки XMPP, MAM и offline-доставку, совпадение ID в истории и веб-событиях, подстановку и повторение ID, архивные настройки, откат транзакции при ошибке, а также формат MIME и сохранение прогресса ActiveSync. Перед выпуском пройдены тесты проекта и целевые проверки XMPP/FlowSync с `-race`; сборка релиза дополнительно запускает тесты в GitHub Actions.

На действующем сервере для предыдущей дополнительной сборки проверены XMPP-авторизация через TLS, discovery XEP-0359/PEP и совпадение курсора MAM с `stanza-id`. Отображение возможностей и фоновая работа конкретного мобильного клиента требуют отдельной проверки на устройстве.

В релизе доступны архивы Linux, macOS и Windows для amd64/arm64, FreeBSD для amd64 и файл `checksums.txt`. Перед обновлением сохраните данные и конфигурацию. Для перехода с 0.9.14 достаточно установить новый серверный бинарный файл и перезапустить службу. Новых миграций базы относительно 0.9.14 нет; удалять учётные записи, сбрасывать папки или OMEMO-ключи не нужно.

## Ограничения

Нативный Push XEP-0357 пока не реализован и не объявляется. Для Secret-iOS нужна интеграция с совместимым push-шлюзом приложения. Существующий Web Push относится к веб-клиенту и не заменяет уведомления внутри Secret. Межсерверная федерация XMPP и совместимый с внешними клиентами MUC также остаются в [плане доработок](https://github.com/rkislov/tayga-mail-server/blob/v0.9.15/docs/xmpp-compatibility-plan.md).

Сервер — Apache-2.0. FlowSync разработан Кисловым Романом Сергеевичем и отдельно распространяется под Apache-2.0. Веб-клиент с OMEMO — GPL-3.0-only.
