# Установка 0.10.5 на mail.kislovs.ru

6 ноября 2026 года установлен GitHub Release v0.10.5, исходный коммит b0c2f0e. Предыдущая установленная версия — 0.10.4.

Проверены все восемь контрольных сумм GitHub Release: семь серверных архивов и неизменённый XPI Thunderbird 2.4.0. GitHub Actions Release 42228674240 завершился успешно. Пройдены полный локальный Go-прогон, целевые race-тесты и нативный Thunderbird E2E с восстановлением старых цепочек.

Перед установкой создана онлайн-копия SQLite, проверенная PRAGMA quick_check, и сохранены прежний бинарник и конфигурация. Каталог отката: `/var/lib/tayga/backups/pre-0.10.5-lrAV8QWr`, база сжата в `tayga.db.gz`. При восстановлении этой копии потребуются штатные остановка службы и восстановление базы; успешная установка базу не заменяла.

Установленный процесс: `tayga-mail 0.10.5 (b0c2f0e) built 2026-11-06T13:52:28Z`. SHA256 работающего бинарника: `d8b77166fa563e7749b885c9d7ccd1e99df30dbbb2143ba70de91b3b72a0527c`. systemd: active/running. `/healthz` возвращает ok, `/readyz` — ready. Открыты стандартные порты SMTP, IMAP, POP3, HTTPS, ManageSieve и XMPP. Контрольная сумма конфигурации после установки не изменилась.

По поручению пользователя удалены старые каталоги резервных копий выпусков pre-* в `/var/backups/tayga` и устаревшие pre-* в `/var/lib/tayga/backups`. Сохранены копии перед 0.10.4 и 0.10.5, а также отдельные материалы восстановления календаря/архивов. После очистки свободно около 8,6 ГБ вместо исходных 1,8 ГБ. Рабочие почта, база и журналы не очищались.

Для ранее загруженных почтовых папок Thunderbird нужно один раз выполнить «Свойства папки → Восстановить папку», затем использовать режим цепочек. Новые письма получают связи при обычной синхронизации.
