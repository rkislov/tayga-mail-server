# Администрирование почты

## DKIM

Откройте меню администратора **DKIM — ключи и DNS**. В списке видны доступные
домены, текущий селектор и состояние подписи. Существующий ключ из
`smtp.dkim` также отображается для соответствующего зарегистрированного домена.

Для домена можно создать RSA-ключ 2048 бит или импортировать закрытый PEM
(PKCS#1 или PKCS#8, RSA не менее 2048 бит). Закрытый ключ можно скачать отдельной
кнопкой. Обычный ответ со списком содержит только публичные данные.

После генерации опубликуйте в DNS TXT-запись, показанную в форме. Например,
для `example.com` и селектора `mail` имя записи — `mail._domainkey.example.com`.
Если панель DNS сама добавляет зону, вводится `mail._domainkey`. Значение
`v=DKIM1; k=rsa; p=…` берётся из формы целиком. PEM в DNS не публикуется.
Затем включите подпись и сохраните привязку. Изменения применяются к новым
отправлениям через SMTP, веб-почту и FlowSync без перезапуска.

Для каждого домена используется одна текущая привязка. Ключ выбирается по
домену отправителя SMTP-конверта. Письма, уже находящиеся в очереди,
сохраняют подпись, полученную при постановке в очередь. Если включённая
привязка ссылается на недоступный ключ, отправка возвращает временную ошибку,
а не уходит без подписи.

Управляемые ключи находятся в `dkim-keys` рядом с корневым каталогом Maildir;
файлы создаются с правами 0600. Каталог должен быть доступен для записи пользователю службы; при установке создайте его с владельцем службы и правами 0700. При резервном копировании сервера сохраняйте
этот каталог вместе с базой данных. Веб-экспорт резервной копии не включает
этот отдельный каталог; PEM можно скачать в меню DKIM. Старые файлы после
замены привязки сохраняются для восстановления, но не используются для подписи.

## Очередь и роли

**Почтовая очередь** вынесена в отдельный пункт меню. Просмотр, количество,
повторная отправка и удаление ограничиваются доменами отправителя, которыми
управляет администратор. Системные отправления с пустым отправителем видны
только глобальному администратору. Список показывает до 200 записей за запрос.

**Роли и права** показывает пользователей по организациям. В текущей модели
организация соответствует тенанту. Назначения меняет глобальный администратор:

- `domain_admin` — выбранные домены;
- `tenant_admin` — все домены тенанта пользователя, включая создаваемые позже;
- `global_admin` — весь сервер.

Администраторы ограниченной области не могут изменять глобальных
администраторов. Администратор домена также не может управлять учётной записью
администратора тенанта. В таблице пользователей есть поиск по имени и email
без учёта регистра, с сохранением проверки области доступа.

## Мониторинг

Графики строятся по наблюдениям каждые пять секунд, пока открыт мониторинг;
сохраняется до 120 точек в памяти страницы. История не восстанавливается после
перезагрузки страницы. После перезапуска сервера временные ряды сбрасываются.

Сетевые линии на общей шкале показывают приём и отправку в КиБ/с по интерфейсам
Linux, кроме loopback. Скорость вычисляется из разницы реальных счётчиков
`/proc/net/dev`. На системах без этих счётчиков интерфейс сообщает об отсутствии
данных. Показатели относятся к сетевым интерфейсам сервера, включая другой
трафик, а не только к почтовым протоколам.
