# Tayga Mail 0.9.43 — ответы iPhone с фотографиями

ActiveSync отклонял отправку, ответ или пересылку с HTTP 400, если запрос
превышал 8 MiB. Например, фотография 7 MiB после MIME-кодирования превышает
этот предел, хотя само письмо укладывается в допустимый размер.

Для SendMail, SmartReply и SmartForward лимит HTTP теперь учитывает
существующий предел MIME 32 MiB, base64-конверт XML и служебные поля.
Ограничения SMTP/пользователя продолжают действовать; предел остальных
команд ActiveSync остаётся 8 MiB. Изменений схемы БД нет.

При превышении транспортного лимита возвращается HTTP 413. Обрыв чтения,
отмена, неверный WBXML и неверный XML отмечаются отдельно. В журнале записываются
объявленный размер запроса, прочитанные байты и предел, без текста и вложений.

Регрессионный тест воспроизводит прежний HTTP 400 на письме с фотографией
7 MiB. После исправления SendMail/SmartReply/SmartForward проходят через WBXML
и XML с проверкой контрольной суммы вложения и защитой повторной отправки.
Дополнительно проверены точная граница, неизвестный Content-Length, ранний отказ
заведомо большого запроса, оборванное чтение, отмена и отсутствие секретов в логе.
Проверены пакет FlowSync, целевые race-тесты и go vet.

Проверка отправки конкретного ответа из Mail на iPhone проводится после
установки; серверные тесты используют изолированные ящики и подмену доставки.
