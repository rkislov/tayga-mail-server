# Установка 0.10.6 на mail.kislovs.ru

6 ноября 2026 года, 17:35 МСК, установлен GitHub Release v0.10.6 на основе коммита b7e448e. Предыдущая установленная версия — 0.10.5. GitHub Actions Release 42233552287 завершился успешно; проверены восемь контрольных сумм (семь серверных архивов и неизменённый XPI Thunderbird 2.4.0).

Пройдены полный локальный Go-прогон, целевые race-тесты и нативный Thunderbird E2E. Локальный benchmark списка 1000 писем: 22,1 мс в 0.10.5 против 4,4 мс в 0.10.6. Регрессионные тесты проверяют пакетную загрузку метаданных с изоляцией папок и прекращение чтения MIME до большого содержимого при запросе метаданных.

Бинарник и конфигурация 0.10.5 сохранены в `/var/lib/tayga/backups/pre-0.10.6-ITG96p7m`. Схема базы не менялась. Файл database-snapshot-reference.txt ссылается на проверенную онлайн-копию базы, созданную ранее в этот день перед 0.10.5: `/var/lib/tayga/backups/pre-0.10.5-lrAV8QWr/tayga.db.gz`. Новая копия базы перед 0.10.6 не создавалась; для отката этого обновления достаточно прежнего бинарника без восстановления базы.

Установленный процесс: `tayga-mail 0.10.6 (b7e448e) built 2026-11-06T14:26:33Z`. SHA256 работающего бинарника: `0c98b1fbac2eb93bd7312128db5c6612806c420d27dba57c62364477754f2110`. systemd active/running, healthz=ok, readyz=ready. Контрольная сумма конфигурации после установки совпадает с исходной. Ошибок уровня error в журнале службы после установки не обнаружено.

## Первые рабочие показатели

Перед обновлением двухминутный срез содержал 424 GetItem: p50 124 мс, p95 1416 мс, максимум 2996 мс. 88 SyncFolderItems: p50 49 мс, p95 4742 мс, максимум 9531 мс.

Первый срез после установки содержал 2314 GetItem: p50 44 мс, p95 98 мс, максимум 2236 мс. 115 SyncFolderItems: p50 65 мс, p95 1310 мс, максимум 3145 мс.

Срезы относятся к разным рабочим интервалам и могут включать разный состав запросов; GetItem включает фоновые запросы заголовков, а не только открытие тела письма. Показатели подтверждают снижение задержек серверной обработки под текущей нагрузкой, но не измеряют напрямую время от щелчка пользователя до показа письма в Thunderbird. Клиент продолжает повторную синхронизацию старых заголовков. Ещё раз восстанавливать папки для 0.10.6 не требуется, отпечатки синхронизации не изменены.
