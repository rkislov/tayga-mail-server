# Tayga Mail Server 0.9.6

## Пользовательский интерфейс

- Плавающие кнопки создания и настроек с анимацией состояния.
- Компактные формы календаря, управление календарём по умолчанию, список предстоящих событий и переключатель прошедших событий.
- Пагинация контактов, выбор нескольких контактов, экспорт VCF и удаление выбранных записей.
- Смена пароля и аватар в профиле; аватар доступен через XMPP vCard.
- Персональная миграция в профиле. Администратор может выбрать целевую учётную запись в пределах своих прав; сервер проверяет область доступа при каждом действии.
- Повтор миграции с сохранением проверки дубликатов; исправлен импорт старых событий и задач CalDAV без DTSTAMP.
- Отображение карты Яндекса для событий с координатами.

## Администрирование и совместный доступ

- Назначение ролей через меню пользователя.
- Просмотр подключений и завершение сессий; управление мобильными устройствами.
- Удаление данных учётной записи на поддерживаемых устройствах ActiveSync 16.1 после подтверждения и выполнения команды устройством.
- Доступ к почтовому ящику, файлам и папкам; публичные ссылки с паролем, сроком действия и правами чтения или записи.

## FlowSync

Модуль разработан Кисловым Романом Сергеевичем и лицензируется отдельно по Apache License 2.0. Исправлено конкурентное создание устройств и ключей синхронизации.

## Проверки производительности

Добавлены воспроизводимые Go-бенчмарки HTTP API и сетевых сценариев HTTPS, SMTP STARTTLS, IMAPS и FlowSync FolderSync по HTTPS в `internal/httpapi`. Они используют изолированную SQLite и синтетические данные; не измеряют максимальное число одновременно работающих пользователей. Сценарий SMTP с ClamAV и Rspamd включается переменной `TAYGA_BENCH_SCAN=1` и требует работающих сервисов сканирования.

Raspberry Pi 4 с 4 ГБ памяти и SSD не проверялась на физическом стенде. Результаты других процессоров нельзя считать измерением производительности Raspberry Pi.
