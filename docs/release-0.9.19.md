# Tayga Mail Server 0.9.19

Исправлено выделение выбранного режима в галерее оформления: при случайной смене фонов теперь выделяется «Случайный фон», включая перезагрузку страницы и смену языка. При выборе конкретной картинки выделяется и сохраняется именно она.

Выпуск включает все изменения [0.9.18](https://github.com/rkislov/tayga-mail-server/releases/tag/v0.9.18): общие группы XMPP/веб, поиск GAL и помещений, серверные правила EWS/Sieve, квоты файлов, автообучение Rspamd, статистику защиты, новый favicon и прозрачные панели.

Проверено в браузере: последовательные обновления без закреплённого фона, сохранение конкретного фона, возврат к случайному режиму и соответствующее выделение в галерее. Изменение не затрагивает почтовую синхронизацию и не добавляет миграций относительно 0.9.18. При обновлении с 0.9.17 применяются миграции 042–044; перед установкой сохраните базу, конфигурацию и предыдущий бинарный файл.

Ограничения протоколов и внешних push-шлюзов описаны в примечаниях 0.9.18 и остаются без изменений. Сервер и FlowSync — Apache-2.0; веб-клиент с OMEMO — GPL-3.0-only.
