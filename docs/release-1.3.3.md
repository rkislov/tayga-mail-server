# Tayga Mail Server 1.3.3

## Русский

- **Markdown в чатах.** Веб-клиент форматирует новые и сохранённые ответы агентов и ботов. Поддерживаются заголовки, выделение, списки, ссылки, таблицы и код. Ссылки на внешние изображения открываются по нажатию.
- **Задания агентов.** При запуске по расписанию агент получает указание выполнить сохранённое задание сразу. Tayga публикует результат в выбранном личном диалоге. При обычном запросе на регулярный ответ агент подсказывает, где настроить расписание.

Обновление не меняет схему базы данных. В выпуск входит расширение Thunderbird 2.5.3.

## English

- **Markdown in chats.** The web client formats new and saved agent and bot replies, including headings, emphasis, lists, links, tables, and code. External images open on click.
- **Scheduled agent runs.** When a saved task starts, the agent is directed to run it immediately. Tayga posts the result in the selected private conversation. When asked to send a recurring reply in a regular conversation, the agent explains where to set up the schedule.

This update requires no database schema changes and includes Thunderbird 2.5.3.
