# Tayga Mail Server 0.9.24

Исправлено распознавание маршрутных квитанций Авиасейлс. Ранее парсер требовал явно подписанные поля и пропускал табличные PDF с датами вида «23 окт 2026» и номерами рейсов через дефис.

- Таблица разбирается с сохранением колонок: аэропорты, даты и местное время вылета/прибытия, рейс и бронь. Несколько пассажиров и перелёты туда/обратно обрабатываются раздельно; платёжная страница не создаёт поездку.
- Для SVO/SVX часовой пояс определяется по проверенному коду аэропорта и дате. Длительность рейса служит дополнительной проверкой. Неизвестный аэропорт или противоречивые данные оставляют карточку на ручное подтверждение.
- Паспортные данные, дата рождения и платёжные реквизиты не переносятся в события. В репозитории находится только обезличенный пример текста; исходный пользовательский PDF не публикуется.
- Имя пассажира видно в списке и окне проверки. При сохранении или пропуске одного сегмента остальные карточки остаются в окне.

Для уже полученного письма нажмите **Из билета** повторно. Новая почта обрабатывается по режиму, выбранному в **Профиль → Билеты и поездки**. Настройки пользователей не меняются, массовый повторный разбор старой почты не запускается. Новых миграций БД нет.

Проверки: исходный PDF через MIME/pdftotext локально; обезличенная регрессия двух пассажиров и четырёх сегментов; создание личных событий с правильными UTC-моментами и дедупликация; неизвестные аэропорты, ошибочные даты, расхождение длительности, изоляция страниц; Go-тесты и race-проверки билетов/хранилища/API; сборка веб-клиента и браузерный сценарий нескольких карточек, включая мобильную ширину.

Подробнее: [билеты и личный календарь](https://github.com/rkislov/tayga-mail-server/blob/v0.9.24/docs/travel-tickets.md).
